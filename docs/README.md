# LiDirt docs (repo)

Product decisions and the full iOS scan MVP technical spec are maintained in the LiDirt Project store. This repo implements that slice.

## Implemented here

- Native SwiftUI + ARKit/RealityKit capture app (`LiDirt/`)
- On-device multi-pass DEM (~5 cm), quality score, heightmap upload package
- Device gate: LiDAR Pro only
